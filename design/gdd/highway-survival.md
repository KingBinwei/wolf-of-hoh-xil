# 可可西里的狼 — 公路求生 游戏设计文档

> 基于《可可西里的狼（第三版）》中篇小说蓝本
> 6章节制，章节存档，荒野探索 + 公路博弈 + 狼同伴AI + 多重结局

---

## 1. Overview

一款俯视角生存叙事游戏。玩家扮演一只在领地争夺中落败、右后腿永久残疾的老狼，在可可西里G109国道边缘与荒野腹地之间求生的6个章节中，招募同样被驱逐的狼同伴，在合作与博弈的张力中，决定自己最终以什么身份走向终点。

### 核心张力

不是"打怪升级"。是两套生存逻辑之间的持续摇摆：

- **公路**：廉价热量，但每一口都在腐蚀你的野性。你的同伴中有人会被碾死。
- **荒野**：保留狼的身份，但猎物稀少，你和你的同伴都是残破之躯。

### 核心体验支柱

1. **残破之躯的沉重感** — 你不是英雄。你拖着一条废腿。你的同伴也一样。
2. **信任与背叛的博弈** — 同伴不是随从。他们有自己的性格、饥饿、恐惧和算计。
3. **公路的冰冷暴力** — 钢铁不恨你，它只是运转。橡胶子弹不恨你，它只是执法。
4. **荒野的沉默尊严** — 你可以选择不吃那块生肉，转身走回地平线。

## 2. Player Fantasy

> 你是一只被逐出领地的老狼。你的右后腿废了。公路边有唾手可得的热量，也有碾碎一切的钢铁。荒原深处有沉默的尊严，也有缓慢的饿死。
>
> 在路上，你遇到了和你一样残破的同类。你们可以一起狩猎，也可以互相撕咬。你们可以分享食物，也可以趁对方不备独吞。
>
> 当闪电照亮那条十二米宽的黑色死地时——你选择成为什么？

### 情感弧线

| 章节 | 情感基调 | 玩家应该感受到 |
|------|---------|--------------|
| Ch1 | 孤独、绝望、发现 | "我活不下去了……但这公路上有吃的" |
| Ch2 | 希望、谨慎的信任 | "还有一个和我一样的……也许我们可以一起" |
| Ch3 | 协作、张力初现 | "合作能让大家都活下来，但凭什么我要分给他？" |
| Ch4 | 冲突、背叛、失去 | "他选择了背叛。现在他死了。我本可以阻止的。" |
| Ch5 | 残酷、清醒、抉择 | "这条公路是一台机器。我们只是齿轮间的肉。" |
| Ch6 | 清算、归宿 | "我选择成为荒野的一部分，而不是公路的寄生物。" |

## 3. 章节结构

### Chapter 1: 十二米宽的沥青 (The 12-Meter Asphalt)

**场景**: 仅公路区域（约200米长的G109国道路段）

**核心玩法**:
- 玩家学习基础操作：移动、躲避车辆、捡拾人类投喂的食物
- 饥饿驱动一切：不吃就会死
- 食物落在公路上，竞争在于"什么时候冲出去捡"
- 第一次见识重卡的威力——推开的狂风就能把你掀翻

**关键剧情节点**:
1. 开局：老狼趴在背风的沙丘下，右后腿残疾，极度饥饿
2. 风向改变，闻到公路的气味
3. 翻过沙丘，第一次看到G109——"十二米宽的黑色带状物"
4. 第一次被重卡擦身而过，感受到狂风的物理冲击（教学关：闪避）
5. 第一辆SUV停下，扔出半截淀粉肠——第一次吃人类食物
6. 在摄入足够食物（累计恢复饥饿度 >60）后，**下一次被车辆撞击不会致死**，而是触发**脚本过渡事件**：
   - 一辆越野车减速拍照，老狼在躲避时被车身擦伤（HP -25 但存活）
   - 翻滚下水泥护坡，摔进排水沟
   - 当老狼爬回路基上时，望见了远处的荒原——"那片灰褐色的、曾经属于他的土地"
   - **章节结束**。存档。进入 Chapter 2。

**存档点**: 章节开始。被撞死 → 从章节开头重新加载。

---

### Chapter 2: 荒野中的同类 (Kin in the Wilderness)

**场景**: 荒原区域（约 500m × 500m 的可探索开放区域）+ 公路边缘（可随时返回公路，但食物来源完全不同）

**新解锁的玩法**:
- **荒野探索**：大面积的冻土、沙丘、干枯的针茅草丛、结冰的河床
- **狩猎小型猎物**：追踪气味 → 潜行靠近 → 爆发扑杀
- **发现狼同伴**：荒野中散布着其他被驱逐的狼

**狩猎系统 (Solo)**:

| 猎物 | 出现区域 | 狩猎难度 | 所需 Muscle | 饥饿恢复 | 野性恢复 | 特殊条件 |
|------|---------|---------|------------|---------|---------|---------|
| 高原鼠兔 | 针茅草丛 | 低 | ≥25 | -15 | +3 | 需要潜行靠近（嗅觉范围>30m才能发现） |
| 旱獭 | 沙丘地带 | 中 | ≥40 | -25 | +5 | 需要冲刺（冲刺冷却8秒） |
| 受伤的藏原羚 | 随机事件 | 中 | ≥35 | -40 | +8 | 荒野中随机刷新，需要嗅觉发现 |
| 倒毙的野牦牛（腐肉） | 冰河附近 | 无需狩猎 | 无要求 | -50 | +2 | 极稀有，但气味浓烈（嗅觉>20即可发现） |

**发现狼同伴**:

散布在荒野中的3只待招募的狼（本区域出现2只，第3只在后续章节出现）：

| 同伴 | 位置 | 状态 | 发现条件 | 招募条件 |
|------|------|------|---------|---------|
| **灰耳** (Grey Ear) | 废弃的旱獭洞穴旁 | 趴在洞口，极度饥饿（Hunger 85） | 在洞穴周围20m触发 | 分给他一块食物（任意），他会跟着你 |
| **独眼** (One Eye) | 冰河边的岩石后 | 正在啃一只死鼠兔，警惕地盯着你 | 靠近岩石 | 不攻击他（选"观察，不靠近"），他会先开口 |

**关键剧情节点**:
1. 进入荒原，学会狩猎鼠兔（教学关：潜行+扑杀）
2. 发现灰耳——第一个同伴。分享食物的选择。
3. 和灰耳一起尝试狩猎更大的猎物（2只狼可以狩猎旱獭，成功率从独狼的30%提升到70%）
4. 发现独眼——他看起来不太可信，但3只狼意味着可以尝试更大的猎物
5. 然而即使3只老残之狼联手，依然无法捕获健康的成年藏羚羊
6. 饥饿将你们逼回了公路的方向——"那个散发着焦油味的黑色地带，至少不会让你们饿死。"
7. **章节结束**。存档。进入 Chapter 3。

### Chapter 3: 公路上的博弈 (The Game on the Asphalt)

**场景**: 公路区域（扩展至约400米长的路段）+ 公路边缘的排水沟和水泥护坡

**新解锁的玩法**:
- **多狼协作抢食**：3只狼同时在公路上争夺食物
- **分配机制**：抢到的食物怎么分？谁吃第一口？
- **初次接触巡护员**：红蓝警灯 + 橡胶子弹的第一次遭遇

**协作与博弈系统**:

当一块食物出现在公路上，3只狼都看到了它。谁去捡？谁望风？谁先吃？

```
决策时刻: 一块烧鸡落在双黄线上

选项A: 自己冲上去（风险: 可能被撞，收益: 独享食物）
选项B: 和同伴协作——一只望风（观察来车方向），一只去取，另一只在路基接应
选项C: 让同伴去取，自己等在路基边缘（安全，但同伴可能独吞）
选项D: 都不去——太重卡太近了
```

**信任度 (Trust) 系统**:
- 每只同伴对玩家有一个0–100的信任值
- 分享食物: +5 到 +15
- 独吞食物: -10 到 -20
- 在同伴危险时救援（比如把被狂风掀翻的同伴拖回路基）: +25
- 见死不救: -30
- 信任影响: 同伴是否听你的指令、是否在关键选择时跟随你的决定、是否在分配时公平对待你

**巡护员初遇事件**:
- 多只狼在公路边缘聚集引起了注意
- 第一次红蓝警灯 + 警笛 + 橡皮子弹
- 不是"boss战"，是"冰冷的法律执行"
- 灰耳提前嗅到了异常（"那辆深色车的气味不对"），给了玩家3秒预警
- 选择: 立刻躲进排水沟 vs 试图再抢一口食物再跑 vs 警告同伴
- 如果不警告同伴 → 独眼被橡皮子弹击中（HP -15，短暂眩晕）→ 他对你的信任 -20
- **此事件过后，公路区域增加了"巡逻"的威胁**：巡护员车辆会不定期出现

**关键剧情节点**:
1. 重回公路，3只狼需要快速建立"安全规则"
2. 第一次食物分配：灰耳愿意分享，独眼想独占
3. 巡护员第一次出现——"那种红蓝色的光在闪烁，那不是车灯，是权力的光谱"
4. 如果独眼受伤，玩家需要决定是否分给他额外的食物（"他受伤了，但这是他自找的"）
5. 远处，出现了新的车灯光点——意味着更激烈的竞争即将到来
6. **章节结束**。存档。

### Chapter 4: 裂痕 (Fractures)

**场景**: 公路区域（扩展至800米路段）+ 新增竞争对手的领地区域

**新解锁的玩法**:
- **竞争狼群**：3只陌生的年轻公狼 + 1只流浪獒犬出现在公路上
- **同伴个性冲突**：灰耳主张退让，独眼主张抢先，白爪（新同伴）犹豫不决
- **狼群分裂**：同伴可能因为策略分歧或信任破裂而离开

**新的竞争者**:

| 竞争者 | 特点 | 策略倾向 | 结局可能性 |
|--------|------|---------|-----------|
| 年轻公狼A | 最强壮，最冲动 | 直接冲上双黄线抢食 | 被重卡撞死（Ch4或Ch5必死） |
| 年轻公狼B | 次强壮，跟在A后面 | 模仿A，但稍有犹豫 | 可能存活，可能死亡 |
| 年轻公狼C | 最弱小，但最狡猾 | 等别人先冲，吃剩下的 | 生存概率最高 |
| 流浪獒犬 | 体型最大，但不懂公路规则 | 试图威吓所有狼 | 被橡皮子弹击中后逃离 |

**新同伴登场**:

| 同伴 | 位置 | 性格 | 特殊能力 | 招募条件 |
|------|------|------|---------|---------|
| **白爪** (White Claw) | 公路排水沟，瑟瑟发抖 | 年轻（3岁），左前爪有旧伤但肌肉尚可，忠诚但缺乏主见 | 冲刺可用（肌肉值55，是所有同伴中最高的） | 在竞争者到来后，白爪被年轻公狼群驱逐出有利位置，如果你给他一块食物他会加入 |

**资源分配博弈**:

当多只狼（你的团队 + 竞争狼群）同时盯上同一块食物：

```
博弈矩阵 (简化版):

你和灰耳同时看到一块食物。两个选择: 冲(Fight) 或 等(Wait)

你\灰耳 | Fight       | Wait
Fight    | 都冲，可能被车撞 | 你抢到，灰耳没吃到
Wait     | 灰耳抢到，你没吃到 | 都没冲，食物被竞争者拿走

在"冲/等"决策上加入车辆风险后:
如果此时一辆重卡正在靠近 → Fight 的期望收益急剧下降
但如果你极度饥饿 → Fight 的诱惑急剧上升
```

**裂痕事件**:
- 如果玩家连续3次在食物分配时选择独吞 → 灰耳的信任降到<30 → 触发: "灰耳不再等你分配食物了。他会自己冲上去抢。"
- 如果独眼的信任降到<20 → 触发: "独眼加入了竞争狼群的阵营。他现在和你抢同一块食物。"
- 如果白爪的信任保持>60 → 触发: "白爪拒绝了年轻公狼群的招揽，选择留下来。"

**关键剧情节点**:
1. 竞争者到来——"他们年轻，肌肉完整，但他们不懂这条公路"
2. 第一次食物争夺战——三只年轻公狼冲上双黄线，你的团队需要决定策略
3. 一只年轻公狼在争夺中被重卡狂风掀翻，摔断肋骨（未死但重伤）
4. 幸存的两只年轻公狼开始学习——"他们比你想象中学得快"——竞争策略进化
5. 内部矛盾激化：灰耳和独眼因为策略分歧而互相对峙
6. **章节结束**。存档。

### Chapter 5: 血与橡胶 (Blood and Rubber)

**场景**: 公路区域 + 暴雨天气系统 + 巡护员加强巡逻

**新解锁的玩法**:
- **极端天气对决策的影响**: 暴雨 = 路面湿滑 = 刹车距离变长 = 重卡更危险
- **狼群内部分裂**: 同伴可能带领一部分狼脱离你的队伍
- **重大角色死亡**: 至少一个有名有姓的角色在本章会死
- **巡护员镇压升级**: 不再只是驱离，而是系统性清除公路边缘的狼群聚集

**分裂机制**:

当狼群规模≥4只且存在严重的信任/策略分歧时，触发分裂：

```
分裂条件: 
  - 群体内存在信任<30的同伴 + 存在信任>60的同伴
  - OR 至少2只同伴在连续3次策略选择中选择了相反的选项
  
分裂结果:
  - 高野性、高肌肉的同伴倾向于"回荒原"
  - 低野性、饥饿的同伴倾向于"留公路"
  - 玩家选择站在哪一边 → 决定了后续的队伍构成
```

**重大死亡事件**:

根据之前的信任值、策略选择和运气，以下角色中至少一个会死：

| 角色 | 死亡方式 | 触发条件 | 最后的话/画面 |
|------|---------|---------|-------------|
| 年轻公狼A | 在雨夜站在双黄线上试图逼停卡车→被碾压 | 必然发生（第10章情节） | "他没有发出一声哀嚎。十二条橡胶轮胎压过去。路面只剩一滩暗红色。" |
| 某同伴（取决于信任值） | 玩家选择了"不警告" → 同伴没注意到来车 → 被撞 | 同伴信任<30 + 玩家不救援 | 同伴在死前短暂地看向你——然后车灯吞没了一切 |
| 流浪獒犬 | 被橡皮子弹打中要害 | 巡护员镇压事件 | 不是狼，但毕竟是一条命 |

**博弈演化**:

经过Chapter 4的经验学习，所有存活的动物（你的团队 + 竞争狼群）开始产生策略分化：

```
策略类型:
  谨慎型 (Cautious): 只在车辆完全停止后才接近食物。在灰耳身上激活。
  投机型 (Opportunist): 在车辆减速时就开始靠近，抢在别人前头。在独眼身上激活。
  寄生型 (Scavenger): 不主动抢，专等别人抢到后去偷/抢剩的。在年轻公狼C身上激活。
  自杀型 (Reckless): 冲进车流中，赌命。在年轻公狼A身上激活（然后他死了）。
```

**巡护员镇压事件**:

三辆巡逻车同时出现，系统性驱离公路沿线所有狼群。这是本章的高潮事件。

- 多把橡皮子弹枪同时开火
- 狼群四散奔逃
- 你的队伍必须做出快速决策：往哪边逃？
- 如果逃向荒原 → 有同伴可能跑散，之后需要找回
- 如果逃向排水沟 → 暂时安全，但巡护员可能停留很久

**关键剧情节点**:
1. 暴雨天气到来——"雨水砸在沥青上，溅起白色的雾气"
2. 年轻公狼A站在双黄线上试图逼停重卡——被碾压而死
3. 目睹碾压的瞬间：你的同伴们的反应各不相同（灰耳沉默，独眼说他蠢，白爪身体在发抖）
4. 巡护员系统性清场——"那种红蓝色的光再次亮起，但这次是三道，同时"
5. 在混乱中，至少一个同伴可能死亡、失踪或背叛
6. 当一切平息后……闪电劈开夜空，老狼看着双黄线上那片被雨水冲刷的暗红色
7. **章节结束**。存档。

### Chapter 6: 地平线之外 (Beyond the Horizon)

**场景**: 公路 + 荒原 + 雪山脚下（最终场景）

**核心玩法**:
- **最终决策**：在经历了前5章的一切之后，做出最终的生存选择
- **没有回头路**：本章的选择不可逆，通向不同的结局

**结局触发条件与设计**:

#### 结局 A: 荒野之王 (Wolf King)
**触发条件**:
- Wildness ≥ 60
- Muscle ≥ 30（至少还能狩猎）
- 至少1只同伴的 Trust ≥ 70
- 在 Chapter 6 的关键选择中选择"带领剩下的同伴回荒原"

**剧情**:
```
你们三只（或两只，或四只）残破的老狼，拖着深浅不一的腿，
踩着积雪，一长一短地走回了荒原深处。

春天来的时候，灰耳在一个废弃的旱獭洞穴里找到了可以躲避风暴的巢穴。
白爪的肌肉恢复得比预期好——他毕竟还年轻。
独眼……独眼在第二个月离开了。没人知道他去了哪里。

而你——你趴在洞口，浑浊的琥珀色眼睛望着地平线。
你的右后腿每到阴天还是会疼。
但你闻到了。西北风里，有藏羚羊群。
它们在回来。

你没有死在这条公路上。

【终局画面: 老狼的身影映在雪山脚下的夕阳中，身边还有同伴的轮廓。】
```

**Gameplay 尾声**: 可以在荒原中自由漫游，狩猎，与同伴互动。没有时间压力。这是你的结局。

---

#### 结局 B: 被放逐者 (The Exiled One)
**触发条件**:
- 至少1只同伴的 Trust < 20
- 玩家在食物分配中多次独吞
- 同伴人数≥2

**剧情**:
```
在一个没有车灯的夜晚，你醒来时发现他们围住了你。
灰耳站在左侧，独眼站在右侧。白爪在远处，低着头。

没有撕咬。不需要撕咬。
你拖着你那条废腿，慢慢站起来。你看了灰耳一眼。
他没有看你。

你转过身，一瘸一拐地走进了荒原。

身后，公路的引擎声继续轰鸣。
没有同伴会再分给你食物，也没有同伴会帮你望风。
在零下三十度的荒野深处，一只残废的老狼，独自等待着体内最后一卡路里烧完。

【终局画面: 老狼独自趴在雪地中，呼吸越来越慢。雪花慢慢覆盖了他的脊背。】
```

**Gameplay 尾声**: 玩家可以在荒原中移动，但饥饿条不断增长。没有任何食物来源（独狼无法狩猎，公路已被同伴占据）。饥饿归零 → HP归零 → 死亡。这是一个缓慢的、不可逆的结局。

---

#### 结局 C: 公路的寄生物 (The Parasite)
**触发条件**:
- Wildness ≤ 15
- 持续在公路上依赖人类投喂超过15天（游戏内时间）
- 没有主动进入荒原探索超过10分钟（实时）

**剧情**:
```
你忘了鼠兔的气味。
你忘了冲刺时后腿蹬地的感觉。
你只知道：白色越野车减速的声音 = 食物。

你趴在距离白线六十厘米的位置。
你的肌肉已经萎缩到无法支撑你站起来的程度。
但你不需要站起来。食物会自己掉到你面前。

你不再是一只狼了。
你是这条公路上众多碳基寄生物中的一个。
你不狩猎。你不战斗。你只是等待，吞咽，消化，再等待。

直到你再也等不来下一辆车。

【终局画面: 老狼趴在水泥护坡下，双眼仍然死死盯着五十米外的沥青路面。
但那双眼睛已经浑浊了。他没有在看任何东西。他只是……还在那里。】
```

**Gameplay 尾声**: 玩家被锁定在公路边缘。无法移动超过10米。只能等待投喂。食物越来越稀疏。游戏无限循环，越来越无聊——这是故意的。玩家最终会手动关闭游戏，而这本身就是这个结局的寓意。

---

#### 结局 D: 荒野的回归 (The Return) — 原版结局
**触发条件**:
- Wildness ≥ 40
- 在 Chapter 6 的"最终选择"事件中，拒绝人类投喂的生肉，独自走入荒原
- 同伴可以存活也可以不存活——这是一个关于"自己"的选择

**剧情**:
```
越野车停下。车窗降下。
一块带着清晰肌肉纹理、边缘包裹着白色脂肪的生肉被扔了出来。
它砸在湿滑的黑色沥青上，溅起几滴浑浊的雨水。

你的胃壁本能地抽搐了一下。
但你转过了头。

你踩着那条半米宽的交界线——一边是黑色沥青，一边是冻土——
一长一短，一长一短，背对着轰鸣的车流，向着灰色的地平线走去。

你拒绝了最后一块免费的热量。
你选择带着饥饿，以一只狼的身份，消失在白毛风中。

【终局画面: 一串深浅不一的脚印，背对公路，延伸进无垠的白色荒原。】
```

---

#### 结局 E: 死在公路上 (Death on the Asphalt)
**触发条件**: 在任何章节被车辆撞死（非脚本擦伤）

**剧情**: 取决于玩家死时的状态：
- 如果 Wildness > 50: "他的瞳孔最后倒映的是荒原的方向。"
- 如果 Wildness < 20: "他到死都在盯着沥青上的那片油渍。"
- 如果身边有同伴: "灰耳在他的尸体旁站了整整一分钟，然后低下了头，叼走了他嘴边那半块还没咽下去的馒头。"

**处理**: 读取章节存档。

### 4.2 信任系统

每只同伴对玩家的信任值独立计算，0-100。

| 行为 | 信任变化 | 备注 |
|------|---------|------|
| 分享食物（均分） | +10 | 如果同伴当前饥饿>70: +15 |
| 分享食物（但自己拿大头） | +3 | 如果同伴信任<40: -2 |
| 独吞整个食物 | -15 | 如果同伴当时也极度饥饿: -25 |
| 在同伴危险时救援 | +25 | 唯一的单次最大信任增益 |
| 见死不救 | -30 | 可能直接触发背叛/离开 |
| 在巡护员出现时警告同伴 | +15 | 独眼对这种行为额外+5 |
| 在巡护员出现时不警告 | -20 |
| 用玩家的身体挡住来车方向，让同伴先取食物 | +20 | 高风险高回报 |
| 让同伴去取食物，自己等在安全处 | -5 | "你让他去冒险" |
| 成功合作狩猎大型猎物 | 所有参与同伴互相+5 |

**信任阈值效果**:

| 信任范围 | 行为变化 |
|---------|---------|
| ≥80 | 同伴会主动把他藏的食物分给你。在分裂事件中必然站在你这边 |
| 60–79 | 正常协作。听从你的指令。公平分配 |
| 40–59 | 开始犹豫。在策略选择时可能选和你不同的选项 |
| 20–39 | 不再听指令。自己冲上去抢食物。可能偷你的储备 |
| 0–19 | 随时可能背叛。在分裂事件中必然站在你的对立面。可能加入竞争狼群 |

### 4.3 同伴AI架构

每个同伴每帧执行以下决策循环：

```
1. 感知 (Perception)
   ├─ 扫描周围车辆（速度、距离、减速趋势）
   ├─ 扫描视野内的食物（位置、类型、竞争者状态）
   ├─ 感知玩家当前位置+状态（饥饿、受伤）
   └─ 感知其他同伴+竞争者的位置和状态

2. 评估 (Evaluation)
   ├─ 计算"当前最紧迫需求"：饥饿值 → 饥饿紧急度
   ├─ 计算"安全系数"：附近车辆的速度×距离 → 风险值
   ├─ 查询"信任值"：对玩家的信任 → 合作意愿
   ├─ 查询"性格权重"：谨慎型给风险更高的权重；鲁莽型给风险更低的权重
   └─ 输出: 一个优先级排序的动作列表

3. 决策 (Decision) — 基于性格+信任+当前状态的加权随机选择
   ├─ 如果信任≥60 + 玩家发出了指令 → 大概率执行玩家指令
   ├─ 如果信任<40 → 忽略玩家指令，按自己的评估行动
   ├─ 如果饥饿>90 → 无视风险，直接冲向最近的食物
   └─ 如果饥饿<30 → 更谨慎，愿意等待更好的时机

4. 执行 (Execution)
   └─ 移动、等待、冲刺、叼起食物、进食、分享、逃离
```

### 4.4 同伴招募时间线

|------|--------|---------|------|
| Ch2 | 灰耳 + 独眼 | 荒原 | 灰耳: 分食物; 独眼: 不攻击 |
| Ch3 | — | — | 只有已有同伴 |
| Ch4 | 白爪 | 公路排水沟 | 分食物，不被竞争狼群吓走 |

## 5. 狩猎系统

### 5.1 狩猎流程

```
1. 探索阶段
   在荒野中游荡 → 嗅觉范围内检测到猎物气味
   → 屏幕上出现气味颗粒（颜色越深 = 越近）

2. 潜行阶段
   压低身体（按住潜行键） → 移速降至30%但噪音为0
   → 从下风向接近（猎物不会察觉）
   → 从上风向接近 → 猎物在20米外就会警觉并逃跑

3. 判断阶段
   到达有效距离 → 游戏暂停，弹出判断窗口:
   - 猎物的种类、大小、健康状态
   - 需要的肌肉值（如果不足，按钮灰掉）
   - 同伴数量加成显示
   - 成功率预估

4. 扑杀阶段
   按下扑杀 → 肌肉值check:
     - 成功 → 猎物死亡，获得热量
     - 边缘成功（肌肉值刚好及格）→ 猎物被咬伤，追一段后成功（消耗额外饥饿）
     - 失败 → 猎物逃脱，消耗饥饿+肌肉值微损+10秒的"扑空"僵硬
```

### 5.2 猎物分级与队伍限制

| 猎物 | 最小 Muscle | 最小队伍人数 | 推荐队伍 | 难度 | 饥饿恢复 | 野性奖励 |
|------|------------|------------|---------|------|---------|---------|
| 高原鼠兔 | 25 | 1 | 1 | 易 | -15 | +3 |
| 雪雀（鸟类） | 20 | 1 | 1 | 极难（需要精准时机） | -8 | +2 |
| 旱獭 | 40 | 1 | 2 | 中 | -25 | +5 |
| 高原兔 | 35 | 1 | 2 | 中 | -20 | +4 |
| 受伤的藏原羚 | 30 | 2 | 3 | 中 | -40 | +8 |
| 老弱的藏羚羊 | 45 | 3 | 4 | 难 | -55 | +10 |
| 成年藏原羚 | 60 | 4 | 5 | 极难 | -70 | +15 |
| 倒毙野牦牛（腐肉） | 无 | 1 | 1 | 无需狩猎 | -50 | +2 |
| 健康的成年藏羚羊 | **不可狩猎** | — | — | — | — | — |

> **设计原则**: 老狼群体永远无法回到巅峰掠食者的状态。即使5只狼全部招募，你们的肌肉总和也远不如一只壮年狼。你捕猎的不是藏羚羊，是那些和你们一样——残的、老的、被淘汰的。

### 5.3 合作狩猎机制

当多只狼共同狩猎时：

1. **包围加成**: 每增加一只狼，猎物逃脱概率 -15%
2. **耐力接力**: 如果第一只狼扑空，第二只可以立即接力（前提：第二只的肌肉≥要求值）
3. **分配问题**: 狩猎成功后 → 触发分配界面 → 肉量有限 → 由谁先吃？吃多少？
   - 如果队友信任高：可以公平分配（所有参与者饥饿-等量，信任+）
   - 如果队友肌肉值高但信任低：他可能要求更多（"我出的力最大"）
   - 玩家的选择影响信任和后续协作

## 6. 公路投喂与竞争系统

### 6.1 投喂物掉落机制

| 车辆类型 | 减速概率 | 投喂概率 | 投喂物 | 落点 | 备注 |
|---------|---------|---------|--------|------|------|
| 越野车/SUV | 60% | 40% | 淀粉肠、馒头、烧鸡、生肉 | 双黄线上(50%) 或 路肩(50%) | 经常拍照 |
| 皮卡 | 40% | 30% | 馒头、油炸淀粉、骨头 | 路肩上(70%) | 中国人常开的车 |
| 轿车 | 20% | 10% | 饼干、面包 | 白线边缘 | 很少投喂 |
| 重卡 | 0% | 0% | — | — | 从不停止，即死 |
| 巡逻车 | 100%停下 | 0% | — | — | 驱离，不投喂 |

### 6.2 竞争策略博弈

当多只狼（你的队伍 + 竞争狼群）同时盯上同一块食物：

```
场地: 一块食物落在双黄线上。
参与者: 你、灰耳、独眼 vs 年轻公狼A、B、C

时间线:
T-2s: 越野车正在减速（还未完全停止）
T-1s: 年轻公狼A开始向食物方向移动
T-0s: 食物落地

轮到你决策:
  A) 立刻冲刺（抢在公狼A之前，但越野车还在滑行，有被剐蹭风险）
  B) 等车完全停止（更安全，但公狼A会先到达食物）
  C) 让同伴先上（指定灰耳或独眼前冲，自己在路基接应）
  D) 不参与（让竞争狼群抢，观察他们的行为）

后果矩阵:
  如果你选A + 公狼A也冲 → 你们在双黄线上相遇 → 可能发生撕咬
  如果你选A + 公狼A没冲 → 你独享食物
  如果你选B → 公狼A拿到食物，但他可能在返回时被另一辆车……
  如果你选C + 灰耳 (Trust 70) → 他会分享
  如果你选C + 独眼 (Trust 25) → 他可能独吞
```

### 6.3 AI策略演化

竞争狼群的策略不是固定的。它们会从死亡中"学习"：

```
第N天: 年轻公狼A被重卡撞死 → 
  幸存者B和C的"鲁莽系数" -0.15（变得稍微谨慎）

第N+1天: 谨慎的公狼C在路边等了很久才行动，成功安全获得食物 →
  幸存者B的"鲁莽系数" -0.10（进一步谨慎）

第N+3天: 但如果谨慎导致连续3次被其他狼抢先 →
  幸存者B的"鲁莽系数" +0.05（"不冲就没得吃"）
```

这种演化创造了一个动态的、不可预测的竞争环境。

## 8. 游戏系统架构

### 8.1 核心属性（每只狼独立）

## 9. Formulas

### 9.1 狩猎成功率

```
P(success) = base_chance × muscle_factor × party_factor × weather_factor

base_chance: 猎物类型基础成功率
  - 鼠兔: 0.8, 旱獭: 0.5, 高原兔: 0.6, 受伤藏原羚: 0.55
  - 老弱藏羚羊: 0.35, 成年藏原羚: 0.2

muscle_factor = clamp(player_muscle / required_muscle, 0.3, 1.0)
  - 如果 muscle = required: 1.0
  - 如果 muscle 超过要求: 仍然 1.0（上限）
  - 如果 muscle 低于要求: 线性下降到 0.3

party_factor = 1.0 + (party_size - 1) × 0.15
  - 1只狼: 1.0, 2只: 1.15, 3只: 1.30, 4只: 1.45, 5只: 1.60

weather_factor:
  - 晴天: 1.0, 阴天: 0.95, 暴风雪: 0.7, 沙尘暴: 0.65, 暴雨: 0.75
```

### 9.2 同伴决策权重

```
action_score(action) = 
    hunger_urgency × w1 +
    safety_evaluation × w2 +
    trust_modifier × w3 +
    personality_bias(action, companion_type) × w4

其中:
- hunger_urgency = clamp(current_hunger / 100, 0, 1)
- safety_evaluation = 1.0 - (vehicle_speed × proximity / max_danger)
- trust_modifier = trust / 100 (对玩家指令)
- personality_bias: 谨慎型对"等待"行动 +0.3 权重，鲁莽型对"冲刺"行动 +0.3 权重
```

## 10. Edge Cases

### 10.1 所有同伴都死了
如果所有同伴都死亡/离开 → 游戏回退到独狼模式（类似Chapter 1）。但老狼的物理属性已经不可逆地退化了。结局B（被放逐者）或结局C（寄生物）概率大幅增加。结局A不再可能。

### 10.2 玩家在荒野中饿到濒死
如果 Hunger ≥ 95 且 Muscle < 20（无法狩猎任何活物）→ 触发"最后的挣扎"事件：一只鼠兔意外地出现在很近的距离。这是一个奇迹。但如果你连这都抓不住（肌肉<20，success_chance = 0.3 × 0.3 = 9%）→ 饿死。

### 10.3 章节转换时跨场景数据
所有同伴、属性、信任值通过 autoload 单例 `GameState` 在场景切换时保存。场景切换 = 重新实例化所有狼，然后从 `GameState` 恢复状态。

### 10.4 被车撞的致命vs非致命判定
- 如果撞击力度 < 致死阈值（基于车辆类型+速度）: 受伤（HP -25, Muscle -10），触发击退动画，0.5秒无敌
- 如果撞击力度 ≥ 致死阈值: 即死
- **Chapter 1 特殊规则**: 第一次撞击在"已累计摄入>60饥饿恢复"后必定为擦伤（脚本化），这是触发荒野场景转换的剧情需要

## 12. Acceptance Criteria

### 章节相关
- [ ] 6个章节各有明确的开始存档点和结束条件
- [ ] Chapter 1 的脚本擦伤事件正确触发荒野场景转换
- [ ] 死亡 → 读到章节开头存档
- [ ] 章节转换时所有狼的状态正确保存与恢复

### 同伴系统
- [ ] 5只同伴可在正确的时间点和条件下招募
- [ ] 每只同伴展现与性格描述一致的行为（灰耳预警、独眼偷藏、白爪模仿、断尾鲁莽、老疤叙事）
- [ ] 信任系统正确影响同伴的指令遵循度和分配行为
- [ ] 同伴可在低信任/高饥饿/策略分歧时离开或背叛

### 狩猎系统
- [ ] 不同猎物需要正确的肌肉值和队伍规模
- [ ] 合作狩猎加成正确计算
- [ ] 健康的成年藏羚羊永远不可狩猎（无论队伍多大）

### 竞争系统
- [ ] 竞争狼群的策略随时间演化（从死亡中学习）
- [ ] 竞争狼群和玩家的队伍在食物争夺中产生有意义的博弈选择

### 结局
- [ ] 5种结局均可在满足条件时正确触发
- [ ] 结局B的"缓慢饿死"体验是故意设计的不可逆过程
- [ ] 结局C的"寄生物"状态正确锁定玩家的移动范围

### 技术
- [ ] 荒野场景至少 500m×500m 可探索区域
- [ ] 所有狼（玩家+同伴+竞争）的6属性系统正确计算和显示
- [ ] 天气系统产生可见的环境变化和gameplay影响
